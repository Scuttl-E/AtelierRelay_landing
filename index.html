Atelier

Start with the idea. Build the project around it.

Begin with a note, plan or rough direction, then build on it in the Atelier with the notes, links, media and supporting material the work needs. Notes can be split into tabs, references stay attached to the thought, and related media can be kept together in stacks as the work is edited or developed. In-app tools such as Sketchpad and Calculator sit alongside the work, so the material, versions and tools behind a project stay connected and organised as it takes shape.

When you want AI involved, connect the current thought directly to your preferred model. AtelierRelay supports Codex CLI through your signed-in ChatGPT account, alongside Anthropic, OpenAI, OpenAI-compatible services and custom endpoints. The conversation works with the thought's own notes, links, media and structured content, with modes ranging from read-only discussion to confirmed or autonomous changes.

Relay

Give coding agents the context behind the code.

Repo-Link carries the thinking behind a project into the repository itself. Notes, references, media and custom instructions are organised into a structured, indexed context layer, so coding agents know what material exists and exactly where to find it without rebuilding the project brief in every prompt.

With Two-Way Link, AtelierRelay can look the other way too. The in-app conversation can search and read safe repository files when needed, bringing project context and implementation into the same discussion without loading the entire codebase.

The same project material can also leave AtelierRelay as a styled PDF or portable Relay bundle for sharing, transfer or backup.

Atelier

The workshop where a thought becomes a project.

Atelier is where the project takes shape. Use the rich note editor to write and organise the work, with separate tabs, formatting, dictation and titled code blocks available when needed.

Save links, images, documents and other media directly into the project instead of leaving them scattered across browser tabs and files. Open them beside the work, or add useful items to Notes as structured reference blocks that can be arranged within the note and carried through into documents generated from the project. Built-in tools assist with practical tasks such as quick calculations and conversions. Sketchpad gives you a quick way to create new visual material or mark up and edit existing images, which can be saved as stacked variants of the original or as separate assets.

Open a project in Expanded View for a focused look at its material, then move into Fullscreen when you need a larger, configurable workspace. Choose which panels are visible, resize them around the work, and keep links, media or an AI conversation open beside the active material. Each project retains its own Fullscreen layout, so it reopens exactly as you left it.

Working views

One project, three scales of workspace.

Home view

Choose where to begin.

Home View is the compact index for your ideas, tasks and projects. Create new items, search, filter or reorder existing items, and mark any as priority to keep important work at the top. Dock it to either edge of the desktop for quick access.

Expanded view

Bring the Atelier into view.

Click a project to open its Atelier as a focused, scrollable workspace. Notes, Links and Media remain available as tabs within the same view, with three preset widths controlling how much of the desktop the workspace occupies.

Fullscreen view

Open the complete Atelier.

Fullscreen View turns the chosen display into a complete project workspace, bringing its main working areas together in one view. Links, Notes and Media occupy dedicated re-sizeable columns, with supporting tools below, while each project remembers the layout created for it.

Adapt the Atelier

Arrange the workspace around the work.

Resize panels to give the active material more room, or close the areas the project does not currently need. Keep media items open beside the notes they support, bring an optional AI conversation into the same working view, and switch to Minimal mode when you want the interface to recede and return more of the screen to the project. The Atelier can be shaped into a focused layout for each stage of the work instead of forcing every idea through the same fixed arrangement.

Connected material

Keep references in view—and in context.

Links, images, documents and other media remain part of the project they support. Open one or several in embedded viewers without leaving the workspace, or place them in separate native windows across a multi-display setup when the project needs more room.

Send Links and Media into Notes as structured, readable references rather than loose URLs or file paths. Those references remain connected to their source and carry through cleanly into generated PDF and HTML documents. Images can also be opened in Sketchpad, marked up, and saved back into Media as new assets or related variants.

Optional AI

Work with AI grounded in the project context.

Connect a supported API provider, a custom OpenAI-compatible endpoint, or an installed Codex CLI using ChatGPT sign-in. Each conversation is scoped to the active project and can work from its current notes, described links, supported images, open references and imported PDF text—and, when Two-Way Link is active, inspect safe files in its linked repository on demand.

Choose Read-only for analysis, Confirm to review each supported change, or Autonomous for bounded actions within that project. Keep separate conversations for research, critique or action without repeatedly rebuilding the background.

Relay

Move the work forward in the form that suits it.

The project context remains intact as the working source inside AtelierRelay. Relay sends selected context outward in the form the next destination needs: a readable PDF or HTML document, a portable .tdpack bundle, or indexed Markdown and media for a repository agent.

Each route preserves a different kind of value—presentation for people, editability for another AtelierRelay installation, or machine-readable context for project AI.

CreatePDF

Choose which note tabs to include, retain inline references, and attach selected links or media. Preview the result, then export a shareable PDF or responsive HTML document without rebuilding the material in a separate page-layout tool.

RELAY EXPORT BUNDLE

Package a complete thought or project into a portable .tdpack bundle. Import it into another AtelierRelay installation with its structure preserved and the work ready to continue, or store it elsewhere as a portable backup copy.

Repo-Link

Connect an AtelierRelay project directly to the repository it supports. Repo-Link exports its notes, links, media, code blocks and working context into a structured, indexed part of the repository, giving coding agents access to the background behind the work without having to rebuild that context every time.

With Two-Way Link, the connection also works back into AtelierRelay. When the conversation needs evidence from the codebase, the in-app AI can browse the repository, search its contents and read specific sections of supported text files. Access is read-only and on demand—the repository is not loaded into every conversation, and ignored files, secrets, generated content, binaries and other restricted material remain outside the read path.

Repo-Link adds managed guidance to AGENTS.md, CLAUDE.md or a custom instruction file, directing compatible agents to the AtelierRelay context stored alongside the code. With AGENTS.md, Codex can discover that guidance automatically when the repository is opened. Each linked AtelierRelay project keeps its own separate index and context, allowing multiple projects to share the same repository without their material being mixed together.

Reusable custom instructions let you build your own library of guidance—such as coding conventions, architecture rules, styling guidance, preferred workflows or project standards—and add or remove them from a linked repository with a single click. Create an instruction once, then reuse it across different projects without repeatedly copying the same rules into each repository.

Desktop presence

Starts close at hand. Steps back when you don’t need it.

Use Ctrl + Alt + Space to show or hide AtelierRelay from anywhere, or Ctrl + Alt + N to capture a new thought near the cursor. When left idle, Home can withdraw into the Sidebar Rail or reduce further to the movable Mini-Brain, keeping project context close without leaving a full window on screen.

Sidebar rail

After inactivity, Home View recedes into a slim rail, leaving project markers at the screen edge as a quiet visual reminder of active work. Hover a marker to reveal its associated item without bringing the full app back into view.

Mini-brain

For the lightest desktop presence, AtelierRelay can minimise after inactivity into the movable Mini-Brain. Place the icon where it suits your desktop, then click it whenever you want to restore the app.

Choose from themes built around distinct colours, interface treatments and backgrounds. Every theme can be used with its background image enabled or removed, while selected themes also include optional video backgrounds.

The current theme can be used as the visual source for PDF and HTML output, allowing exported work to retain the same character when that suits the document.
